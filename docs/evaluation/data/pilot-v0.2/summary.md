# Pilot artifact index

The retained JSON contains the registered pilot observations and aggregate data:

- [Metrics](metrics.json): per-case captures, hashes, statuses, replay checks,
  diagnostic contracts, adapter coverage, and execution metadata.
- [Aggregate data](summary.json): separate native-execution and shared-capture
  tracks, including their coverage and denominators.
- [Reader exercise](comprehension.json): scoring, protocol hashes, and limits.

See the [pilot overview](../../pilot-results.md),
[validation notes](../../validation.md), and [method](../../method.md) for scope
and reproduction guidance. Raw output and repository snapshots remain local.
